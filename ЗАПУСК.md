# Как запустить FinanceFlow

В архиве полный исходный код: JavaScript-интерфейс на английском, Python/Django, миграции и конфигурация PostgreSQL.

## Через Docker

1. Установите и запустите Docker Desktop.
2. Распакуйте архив и откройте терминал в папке FinanceFlow.
3. Скопируйте `.env.example` в `.env`.
4. В `.env` задайте свой пароль в строке `POSTGRES_PASSWORD=`. Для локального просмотра оставьте `DJANGO_DEBUG=1`.
5. Выполните:

```sh
docker compose up --build
```

Откройте http://localhost:8000 и создайте аккаунт.

Чтобы заполнить приложение демонстрационными данными, в другом терминале из той же папки выполните:

```sh
docker compose exec web python manage.py seed_demo
```

Демонстрационный вход: `demo@financeflow.local`, пароль `DemoPass123!`. Используйте его только локально. Повторный запуск этой команды заменяет данные демонстрационного аккаунта.

## Без Docker

Установите Python 3.11+ и PostgreSQL 14+, создайте базу и пользователя, заполните `.env` по примеру. Затем запустите `./start.sh` на macOS/Linux или `.\start-windows.bat` на Windows. Подробности — в README.md.
